# AirTutor Experiment Artifacts & Provenance Registry

This directory contains experimental benchmark outputs, publication figures, ablation studies, and serialized model checkpoints for AirTutor.

## 1. Directory Structure & Classification

### 1.1 Final Benchmark Release (Authoritative)
- **[`experiments/final_benchmark/`](final_benchmark/):** Current authoritative release benchmark. Contains `README.md`, `config.json`, `summary.json`, and `metrics.csv` evaluated across 100 held-out simulated learners ($[10000, 10100)$) across 5 independent RL seeds.

### 1.2 Publication Plots
- **`experiments/learning_gain_comparison.png`:** Comparative learning gain by teacher (Random, Fixed, Rule, RL) on held-out learners with 95% confidence intervals.
- **`experiments/training_reward_curve.png`:** Multi-seed training reward trajectories across 300 training episodes.
- **`experiments/reward_ablation_comparison.png`:** Reward function ablation (v1 vs. v2 vs. v3) and resulting pedagogical action distributions.
- **`experiments/state_ablation_deltas.png`:** Observable feature ablation ($\Delta$ vs. full 320-state representation).
- **`experiments/sensitivity_sweep.png`:** 12-axis simulator parameter robustness sweep.
- **`experiments/toy_learning_curve.png`:** Educational toy environment baseline sanity check curve.

### 1.3 Pretrained Model Checkpoints
- **`experiments/trained_q_agent.npy` (12.9 KB):** Serialized $320 \times 5$ Q-table of the trained tabular Q-learning agent. Used by `app/main.py` for immediate startup. Can also be re-trained on the fly in ~0.6 seconds.
- **`experiments/dqn_benchmark/*.pt` (~97 KB each, 10 files, total < 1 MB):** Lightweight PyTorch MLP checkpoints for the optional DQN extension benchmark across 3 conditions (Condition A Full, Condition B No-BKT, Condition C No-Action-History) and 3 random seeds (42, 123, 456). Generated by `python src/evaluation/run_dqn_benchmark.py`.

### 1.4 Historical Experiment Archives
Timestamped directories preserve experiment provenance across development stages:
- **`stage3_benchmark_20260914_142722/`:** Stage 3 initial baseline benchmark (pre-metric-calibration).
- **`stage3_benchmark_20260919_092338/`:** Stage 3 post-metric-calibration benchmark run.
- **`stage3_benchmark_20261002_214652/`:** Final release verification benchmark run.
- **`stage4_experiments_20260914_143855/`:** Stage 4 initial ablation and sensitivity sweep run.
- **`stage4_experiments_20260919_092412/`:** Stage 4 post-calibration ablation and sensitivity sweep run.
- **`dqn_benchmark/`:** Deep Q-Network comparative benchmark and ablation suite artifacts.

## 2. Reproduction Commands

All experiments are fully reproducible from the repository root:

```bash
# 1. Run Core Stage 3 Held-Out Benchmark (Random, Fixed, Rule, RL)
python src/evaluation/compare_teachers.py

# 2. Run Stage 4 Ablations & Sensitivity Sweeps
python src/evaluation/run_stage4_experiments.py

# 3. Run Optional DQN Benchmark Suite (requires PyTorch)
python src/evaluation/run_dqn_benchmark.py
```
